# Instruções para agentes

- Preserve a estrutura e o estilo existentes do projeto.
- Faça alterações apenas relacionadas à solicitação atual.
- Não inclua credenciais, chaves ou dados pessoais em arquivos versionados.
- Execute os testes ou verificações relevantes após alterar código.
- Atualize a documentação quando a mudança afetar o uso do projeto.
