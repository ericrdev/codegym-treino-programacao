# Publicacao\n\nO CodeGym agora e estatico: a pasta `public/` contem toda a aplicacao.\n\n## Vercel\n\n1. Importe o repositorio `ericrdev/codegym-treino-programacao`.\n2. Mantenha o framework como **Other** e publique. A Vercel identifica a pasta `public/`.\n\n## GitHub Pages\n\nNo repositorio, abra **Settings > Pages**, escolha **GitHub Actions** como fonte e publique a pasta `public/` com um workflow de site estatico.\n\nOs exercicios JavaScript rodam no navegador. O historico e salvo em `localStorage`, portanto nao e compartilhado entre dispositivos.
